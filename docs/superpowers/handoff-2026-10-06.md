## Lessons recorded

- Cap verification fan-out in review workflows; prefer fresh-context workflow agents over full-context forks.
- Gate every tool on its own exit code (a pipe to `tail` once hid a failing biome run).
- Never hardcode model ids; resolve tiers from the provider CLIs at launch, falling back to the CLI default.
- Closing finished Orca teammate panes broke teammate creation for the rest of the session (`tmux: terminal_exited`).
