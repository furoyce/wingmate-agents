## What Wingmate is (one paragraph)

A Bun/TypeScript CLI that runs as the **precheck** of a 5-minute Orca automation (`wingmate tick --precheck`, no LLM
in the dispatcher). Each tick reconciles Linear + the Orca fleet + local records, executes outbox intents written by
per-issue coordinator agents (`wingmate issue …` verbs), resumes parked issues on verified owner answers, and claims
eligible labeled issues by creating a `wm-<id>` worktree, installing a kit, and launching a terminal agent with explicit
argv (tier `best` = the provider CLI's configured flagship, never a hardcoded model id). Agents never hold credentials
and never publish; the dispatcher runs path guard → secret scan → dependency policy → push → PR → completion. Linear is
the UI of record (Lifecycle labels `In-Agent / Needs-Human / Review-Ready / Blocked`, one edited status comment, question
comments posted as the "Wingmate" OAuth app). A Linear-like Console is slice 3.

## Lessons recorded

- Cap verification fan-out in review workflows (2 refuters per finding cost 21M tokens; 3 capped agents cost 0.5M).
- The Read tool caps at ~25K tokens per call — page large files by offset.
- Do not hardcode model ids anywhere; resolve tiers from the provider CLIs at launch.
